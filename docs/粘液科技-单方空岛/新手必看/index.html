新手必看

最后更新于 2026年10月31日

游玩前准备​

若你没有客户端，可进入QQ群获取。大部分配置都由管理配置好了。

同时建议从QQ群中直接获取材质包，对于性能较差的电脑，每次进入服务器接收材质包会花费大量的时间，可能导致超过登录时间。

截图

获取新手礼包​

进入服务器之后，你可以在菜单(按Shift+F)，在第一页找到礼包，获取菜单和新手礼包

其中包含钍质工具以及饱和护符等一系列对于前期开荒帮助较大的物品。

空岛创建​

空岛服一定要有空岛，使用该指令创建空岛：

/is create <英文id>
注意

空岛插件不支持中文 id，尝试使用中文 id 时会报错。

详细的管理请输入以下指令：

/is panel

金币​

金币在DFD中是较为重要的资源，无论是前期开荒获取部分物资，

或者是从全球市场\系统商店\玩家QS箱子商店购买物品，亦或者升级岛屿，扩大边界、漏斗、村民上限。

这些操作都要用到金币。金币的余额可以在计分板，顶部，或者使用指令查看：

/cmi money
/money

获取方式​

  • 每日签到(1k/次 奖励随着连签增多)
  • 在线时长奖励(1w/日 270分钟就能拿满)
  • 鱼市(2w 会员可获取更多金币)
  • QuickShop商店
  • 全球市场
注意

在使用QS商店\全球市场时，建议查看群内价格公示表

警告

贩卖部分附属的毕业物品，价格过低/过高的行为可能导致惩罚

点券​

点券是DFD的充值货币，可用于购买部分道具，vip特权，以及其他特权。

警告

未成年人禁止付款，请量力而行！

部分权益有持续时间，请注意查看介绍！服务器周目结束时，仅保留点券/高级称号。

游玩时可用​

飞行在单方空岛是被允许的，输入/fly即可开启飞行模式。

但注意：不要使用挂端对飞行加速，可能导致被ban。

单方空岛会变更周目，大部分数据在周目变更后会重置，谨记。
