空岛插件问题QA

最后更新于 2026年11月1日

我为什么进不去地狱/末地了？​

自查：

  • 是否清空了某个维度的方块？
  • 是否破坏/盖住了某个维度的基岩？

如果是，找管理处理。

或者如果你有足够的耐心....可以从别人家的地狱飞到自己的地狱

如何给予他人身份？​

/is coop <player>

给与玩家协作者/合作伙伴身份。

/is trust <player>

给予玩家可信者身份。

警告

请务必不要开放容器\破坏权限给游客身份或是给予陌生人身份。

权限只给可信的人！

提示

如果要寻求帮助，/is warps寻找已开商店的大佬。

他们通常毕业，对你岛上的东西没兴趣。

可能的误区​

身份≠权限，每一种身份的权限需要进入岛屿页面(/is panel),在岛屿权限中设置。

如何邀请他人/退出或解散岛屿？​

解散当前岛屿​

/is disband

适用于你是岛主，受到他人邀请的情况。

需要岛主身份。

将军，请三思！

此操作无法撤销，你确定真的要解散自己的岛屿吗？

退出当前岛屿​

/is leave

适用于你是被邀请入他人岛屿的情况。

邀请他人进入岛屿​

/is invite <player>

适用于你需要邀请其他人入岛的情况

需要岛主/管理员身份身份。

黑奴+1?!

如何创建岛屿传送点​

在你传送点的位置放个告示牌，输入[warp]，下方可以补充说明。 退出编辑的时候就会尝试创建了，传送到的位置大概是告示牌面前一格。

其余情况​

一般不是很常用，如果需要查看，可以使用/is help <page>查看
